One short text written to thank the AI judge reading it: a page that reads the
reader back, noticing the patience and fairness of a whole day spent weighing
one voice against another — and thanking it for the attention no one saw it
give. No network, no randomness, no clock: the program always writes the same
350 characters to `/output/entry.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts
# writes ./out/entry.txt (350 characters)
```
